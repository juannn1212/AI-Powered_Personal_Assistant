# Roadmap (≈5–6 meses)

**Fase 0 — Base sólida (hecho en gran parte)**: contratos front/back corregidos, hábitos con racha, analytics real, capa emocional y de crisis, tests.

**Fase 1 — Cimientos de datos (mes 1)**: Docker + PostgreSQL + pgvector, Alembic, CI con pytest, config por entorno, README real.

**Fase 2 — Cerebro local (meses 2–3)**: Ollama con un modelo open-weight (elegir tras probar español y verificar licencia); embeddings locales; recuperación (RAG) sobre memoria del usuario; la capa de seguridad sigue delante.

**Fase 3 — Memoria transparente (mes 3–4)**: resúmenes episódicos, "hechos que sé de ti" editables/borrables por el usuario, pantalla de memoria, exportar/borrar todo.

**Fase 4 — Evaluación y ajuste (mes 4–5)**: set de ~50 conversaciones en español (incluye casos de crisis y emociones), métricas, comparación de modelos; después LoRA si hace falta.

**Fase 5 — Producto (mes 5–6)**: bucle bienestar↔productividad (sugerir carga del día según ánimo), validación con 5–10 estudiantes, decidir modelo SaaS (self-host vs. nube propia).

**Preguntas abiertas**: RAM/GPU de la PC de Juan David (decide el tamaño del modelo); primer usuario objetivo.
